# Privacy policy: rtl-fix

_Last updated: 11 November 2026_

`rtl-fix` is a Claude Code plugin that runs entirely on your own computer, inside Claude Code.

## What it handles

- It reads the text of Claude's replies inside your Claude Code session, only to add an invisible Right-to-Left Mark (U+200F) at the start of lines that contain Persian, Arabic or Hebrew letters.
- The changed reply is kept by Claude Code in your session's own transcript, as it would be without the plugin.

## What it does not do

- It does not collect, store, log or keep any data of its own.
- It does not send any data anywhere: it makes no network requests and talks to no service.
- It does not read your files, run commands, or access credentials.
- It does not use analytics, tracking or cookies.
